# Инструкция по запуску проекта (без Docker)

Эта инструкция предназначена для запуска проекта с использованием локально установленного MSSQL Server (в случаях, когда Docker не работает).

## Предварительные требования
*   Установлен **Node.js** (рекомендуется версия 18 или новее).
*   Установлен и запущен локальный **MSSQL Server**.

---

## Шаг 1: Подготовка базы данных
Так как Docker не используется, вам нужно импортировать SQL скрипты вручную (например, через SQL Server Management Studio или Azure Data Studio):

1.  Создайте базу данных (например, `ListDB`) или используйте существующую (например, `master`).
2.  Выполните скрипт `sql/init.sql` для создания необходимых таблиц.
3.  Выполните скрипт `sql/seed.sql` для заполнения базы начальными данными (товары, склады и т.д.).

---

## Шаг 2: Запуск Сервера (Backend)
1.  В корневой директории проекта создайте файл `.env` (можно скопировать `.env.example`) и укажите настройки подключения к вашей локальной базе данных:
    ```env
    PORT=3000
    DB_USER=ваше_имя_пользователя (например, sa)
    DB_PASSWORD=ваш_пароль
    DB_HOST=localhost
    DB_PORT=1433
    DB_NAME=имя_вашей_базы_данных
    DB_ENCRYPT=false
    ```
2.  Установите зависимости сервера (выполнять в корне проекта):
    ```bash
    npm install
    ```
3.  Запустите сервер в режиме разработки:
    ```bash
    npm run dev
    ```
    Сервер запустится на порту 3000 (или том, который вы указали в `.env`).

---

## Шаг 3: Запуск Клиента (UI)
1.  Перейдите в папку `ui`:
    ```bash
    cd ui
    ```
2.  Установите зависимости клиента:
    ```bash
    npm install
    ```
3.  Запустите клиент в режиме разработки:
    ```bash
    npm run dev
    ```
    Клиент запустится и выведет в консоль ссылку (обычно `http://localhost:5173`).

---

## Дополнительно
Если вам нужно запустить **Storybook** для просмотра компонентов, перейдите в папку `ui` и выполните:
```bash
npm run storybook
```

---

## Запуск на Windows (без Docker)

Если вы используете Windows, шаги в целом те же самые, но вот несколько уточнений для удобства:

### 1. Работа с базой данных (SSMS)
Для импорта SQL скриптов на Windows удобнее всего использовать **SQL Server Management Studio (SSMS)**:
1.  Подключитесь к вашему локальному серверу.
2.  Нажмите `File` -> `Open` -> `File...` и выберите файл `sql/init.sql`.
3.  Нажмите `Execute` (или `F5`), чтобы выполнить его.
4.  Повторите то же самое для файла `sql/seed.sql`.

### 2. Создание файла `.env` в консоли
Если вы хотите создать файл `.env` через командную строку:
*   В **PowerShell**:
    ```powershell
    cp .env.example .env
    ```
*   В **Командной строке (CMD)**:
    ```cmd
    copy .env.example .env
    ```

### 3. Запуск команд
Все команды (`npm install`, `npm run dev`) работают одинаково как в PowerShell, так и в CMD. Убедитесь, что вы находитесь в правильной директории (корень проекта для сервера и папка `ui` для клиента).
